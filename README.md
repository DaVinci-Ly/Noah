# منظومة نوح — إدارة مكاتب استيراد السيارات 🇱🇾

منظومة متكاملة وخفيفة مصممة خصيصاً لمكاتب استيراد السيارات من مزادات كوبارت (Copart) والآي آي (IAA) في ليبيا.

---

## المميزات الرئيسية

1. **دخول برقم الهاتف ورمز PIN فقط** (بدون بريد إلكتروني، وبدون الحاجة لرسائل OTP مكلفة).
2. **كاشط ذكي لمزادات Copart و IAA**: جلب فوري لبيانات اللوت، الصور، والضرر بمجرد لصق الرابط أو رقم اللوت.
3. **فك مجاني لرقم الهيكل (VIN)** عبر الاتصال المباشر بوكالة السلامة المرورية الأمريكية (NHTSA vPIC) لملء مواصفات السيارة وسنة الصنع والمحرك أوتوماتيكياً.
4. **حاسبة استيراد مخصصة لليبيا**:
   - شرائح رسوم المزاد الحقيقية (Buyer Fee + Gate Fee).
   - النقل الداخلي الأمريكي (Towing) حسب الولاية.
   - الشحن البحري لموانئ ليبيا (الخمس، بنغازي، مصراتة، طرابلس، طبرق، سرت).
   - عمولة المكتب وسعر صرف الدولار بالسوق الموازي (تحويل تلقائي بين $ ود.ل).
   - زر نسخ فوري لملخص العرض لإرساله للزبون عبر الواتساب.
5. **إدارة المعاملات والسيارات**:
   - دورة حياة واضحة من مسودة وعرض السعر إلى الرسو، النقل، الشحن، التخليص، والتسليم.
   - مقارنة التكلفة التقديرية المعتمدة مقابل التكلفة الفعلية بعد الرسو.
   - سجل مالي تشغيلي لكل سيارة (ما دفعه الزبون، ما دفعه المكتب، والمتبقي).
   - تفاصيل الشحن (الساحة، شركة النقل، الحاوية، رقم البوليصة B/L، المخلص الجمركي، ورابط التتبع).
6. **دليل الزبائن الدائمين**: ملف خاص لكل عميل يجمع كافة سياراته وتاريخ تعاملاته.
7. **واجهة عربية بالكامل (RTL)** بخط Cairo الرسمي وأرقام إنجليزية (0-9) وتاريخ ميلادي متجاوبة بسلاسة مع الهاتف والكمبيوتر.
